# OD-UI-01

为一个小型产品团队设计专业桌面端“发布准备工作台”，用于在上线前发现、分派和解决阻塞项。请创建两个 1440×900 的真实可编辑界面：

1. Release Overview：稳定的产品导航、当前版本与状态、关键准备指标、按严重程度组织的阻塞列表、负责人和截止时间、近期活动，以及明确但不过度突出的主要操作。
2. Blocker Detail：返回上下文、阻塞标题与严重程度、当前状态、说明、负责人、截止时间、检查清单、相关证据、活动记录，以及 Resolve / Escalate 操作。

要求：

- 这是高密度专业桌面客户端，不是营销落地页、卡片仪表盘模板或放大的移动页面。
- 信息层级、表格/列表密度、状态、选中行、错误、禁用和键盘焦点必须清楚；使用真实长度的产品文案。
- 如果当前 Design File 已有语义匹配的 Component、Style 或 Variable，优先复用 linked Instance 和正式设计系统资产；不匹配时再创建新结构。
- 两个界面共享的导航、状态标识、人员、操作与列表模式应保持一致，但不要为了组件化制造无意义包装。
- 保持所有文字、组件、图标和布局可编辑；不要添加需求之外的分析、聊天、计费或团队管理功能。
- 先快速建立两个真实画板并立即完成第一个有意义区域；最终必须检查真实截图、落实具体修正，再完成全部交付。
