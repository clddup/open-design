# OD-LOGO-01

为 OpenDesign 设计一套可进入正式交付流程的品牌 Logo 与桌面应用 Icon。OpenDesign 是 AI-native 通用设计平台，首先服务 UI/UX，也支持 Logo、海报、品牌物料和其他视觉设计。品牌关键词是专业、智能、开放、精确、结构化、可信、现代、克制和创造力。

请创建四个真实可编辑画板：

1. Concept Exploration：三个基于不同生成原理的方向，每个包含独立 Symbol、设计逻辑、黑白轮廓和 32/24/16 px 光学测试。颜色、圆角、旋转或 OD 字母排列变化不能算不同概念。
2. Selected Logo System：选择最强方向，完成 Symbol、Horizontal / Stacked lockup、Wordmark、Light / Dark、Monochrome、Clear space 和最小尺寸。
3. Desktop App Icon：针对 16、24、32、64、128、256、512 px 分别校正比例、留白和视觉重量，并展示 macOS / Windows 使用效果；不能只是把 Logo 缩放进圆角方块。
4. Brand Usage Preview：展示标题栏、启动页、应用列表和深浅色画布中的真实应用。

要求：

- 避免通用 AI 星芒、魔法棒、聊天气泡、大脑、电路、无限符号、简单 OD 拼接、廉价渐变以及对 Figma、Adobe、Canva、OpenAI 或 Cursor 的模仿。
- Logo 几何必须使用可编辑 Path/Vector；完整 Logo、Icon 和 Lockup 使用独立语义 Frame/Group，展示背景与源稿分离。
- 可复用变体建立为 Component，展示稿使用 linked Instance；图层名称稳定、专业。
- 浅色、深色、单色和小尺寸必须独立成立，不能靠说明文字解释一个普通符号。
- 先快速创建四个真实画板并立即完成第一个有意义概念；最终必须检查真实截图、落实具体轮廓或光学校正，再完成全部交付。
