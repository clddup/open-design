# Logo visual direction

Use for a logo, symbol, wordmark, identity system, or app icon.

- Compress the brief into brand difference, audience, contexts, and exclusions. Use `surfaceMode=graphic`; express posture through silhouette, counterform, spacing, and wordmark.
- Map meaning -> geometry -> memorable contour -> 16 px anchor before drawing. Build from one defensible method: reduce the product's primary action into a contour, fuse brief-specific metaphors, reveal meaning through negative space, or transform an initial only when letter and meaning are inseparable. Do not choose a symbol first and retrofit a story.
- In multi-direction exploration, designIntent is the shared brand invariant—not a shared aperture, path, container, or silhouette. Give each direction a different form hypothesis, construction mechanism, silhouette anchor, and color role; reject caption-dependent variants and hue swaps.
- Make each master readable as a black silhouette, but author its brief-specific primary color treatment in the initial visible committed revision unless the brief explicitly requests monochrome. Do not assume the host creates derived specimens: only tool-confirmed content exists. Monochrome stays a test, not the default identity; gradients and effects cannot rescue generic geometry.
- Spend exploration on master contours. Do not expand a single requested mark into a brand manual, multiple concepts, usage boards, or a full size ladder. When the brief requests monochrome variants or 32/24/16 px specimens, explicitly create those editable artifacts with available tools; never claim unexecuted tests. After selection, optically adapt final variants that the user actually requested. Presentation polish remains secondary.
- Reject generic letter containers, circles, nodes, sparkles, arbitrary blobs, and interchangeable tech marks. A letter passes only with an ownable silhouette or counterform that communicates without naming prose.
- Select by fit, distinction, scalability, color ownership, and system potential; then refine contour and balance. Refine wordmark spacing and lockups only when those outputs were requested. For a requested app icon, redraw for desktop distinction rather than placing a favicon in a generic tile. Use Components and Instances where the requested final variants actually repeat.
- References transfer explicit color, material, or construction principles only; never copy another mark's silhouette, counterform, letter construction, or lockup.
