# ADR-0311：计划画板树允许同 ID 原子重建

- 状态：Accepted
- 日期：2026-09-06
- 关联：ADR-0305、ADR-0306

## 问题

普通重构可能在一个事务内删除旧树并重建同 ID Frame。原路径先拒绝计划根删除，又把重建根当成重复创建而移除，导致最终仍应存在的画板无法重构。

## 决策

已建立的计划 Frame 在同批节点命令中删除并重新插入时，按原子重构处理，不使用旧创建阶段的骨架和 region 几何去覆盖新设计。仅删除、不重建的计划根生命周期语义仍待独立处理。

Main 将需要保留的 Frame 身份与 Page 放入内部 `preservedFrames`。它来自当前执行授权，不读取模型同名字段；Provider schema 不暴露，普通与 canonical 模型输入均拒绝，只有可信内部契约传递。

Renderer 复用已有整批 `workingDocument` 预览，在唯一实际提交前确认最终节点仍为 Frame 且位于原 Page。中间命令形式不作为终态证明；重复删除、错误类型或无效文档均不能提交。这里不新增第二个文档状态或完整重复校验，EditorRuntime 仍验证事务 invariant、引用、循环和原子性。

旧 Plan 创建路径、跨页授权、revision、namespace 不变；新几何通过原编辑语义处理，变更后的审核与账本复用真实 ChangeSet。

## 验证与边界

真实首切片→连续编辑→同 ID 整树重建，保留子节点、允许改变宽度，一次提交与一次 undo。错误 Frame 类型、循环、delete→insert→delete 末态缺根均保持原文档和 ledger；内部字段不可由模型伪造。

单独删除计划画板、跨计划移动以及所有普通混合编辑限制仍未全部解决，本次不宣称整个编辑器生命周期已完成。
